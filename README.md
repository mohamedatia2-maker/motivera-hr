# Motivera - موقع المحور للاستشارات والموارد البشرية

موقع إلكتروني متكامل لإدارة واستعراض خدمات الموارد البشرية والاستشارات الإدارية (Motivera / EPEC).

## 📋 المميزات
- **الرئيسية (Home)**: واجهة عصرية متجاوبة بالكامل تدعم اللغة العربية (RTL).
- **من نحن (About)**: نبذة عن الشركة ورؤيتها وأهدافها.
- **خدماتنا (Services)**: استعراض جميع خدمات الموارد البشرية والاستشارات.
- **طلب خدمة (Service Request)**: نموذج تفاعلي لطلب الخدمات والاستشارات.
- **إضافة خدمة (Add Service)**: صفحة مخصصة لإضافة وتخصيص الخدمات.
- **مشاريعنا (Projects)**: معرض للأعمال والمشاريع السابقة.
- **مركز المعرفة (Knowledge Center)**: مقالات وأدلة معرفية في مجال الموارد البشرية.
- **انضم لفريقنا (Careers)**: صفحة التوظيف والفرص المتاحة.
- **تواصل معنا (Contact)**: قنوات الاتصال ونموذج المراسلة.

## 🛠️ التقنيات المستخدمة
- HTML5 (Semantic & RTL Support)
- CSS3 (Responsive Design, Flexbox, Grid)
- JavaScript (Vanilla JS للتفاعل وتجربة المستخدم)
- Font Awesome Icons & Google Fonts (Cairo)

## 🚀 تشغيل المشروع
يمكن تشغيل المشروع ببساطة عبر فتح ملف `index.html` في أي متصفح ويب، أو باستخدام Live Server في VS Code.
